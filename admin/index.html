    新しい機能を入れる（Claudeから届いたzipを使う）

    Claudeから「chii-site.zip」が届いたときに、ここで選んで送ります。スポットのデータと写真はそのまま残ります。先に「GitHubの設定」を済ませてね。

    GitHubの設定（最初の1回だけ）
    1. GitHub でリポジトリを作る：右上の「＋」→「New repository」。名前は自由（例：chii-site）。「Add a README file」にチェックを入れて作ります（空のままだと送れません）。
    2. トークン（鍵）を作る：GitHub の「Settings」→「Developer settings」→「Personal access tokens」→「Fine-grained tokens」→「Generate new token」。「Repository access」は Only select repositories で、いま作ったリポジトリだけを選びます。「Permissions」→「Repository permissions」の Contents を Read and write にして作成し、表示された文字列をコピーします（もう一度は見られません）。
    3. 下の3つの欄に入れる：「ユーザー名/リポジトリ名」「ブランチ」「トークン」を入れて、「保存して接続テスト」を押します。
    4. テストが通ったら、「サイト全体を送る（最初の1回）」を押します。サイトの全ファイルとスポットの写真が GitHub に入ります。
    5. Cloudflare Pages を GitHub につなぐ：Cloudflare の「Workers & Pages」→「Create」→「Pages」→「Connect to Git」で、このリポジトリを選びます。「Framework preset」は None、「Build command」は空、「Build output directory」は / にして「Save and Deploy」。
    6. できあがったアドレス（○○.pages.dev）が、これからの公開アドレスです。以前のアドレスと違う場合は、新しい方を使ってね。

    トークンは、いま使っているこの端末のブラウザにだけ保存します（サイトや GitHub には出ません）。別の端末で使うときは、そこでもう一度入れてね。共有のパソコンでは、使い終わったら下の「設定を消す」を押してください。

    ZIPで手動更新する（予備）

    GitHub につないだプロジェクトには、ZIPのアップロードは使えません。
