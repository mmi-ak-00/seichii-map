聖ちぃ巡礼マップ（トップ＋地方ページ＋管理ページ）

【公開のしかた】
このフォルダの中身（index.html / regions / admin / css / js / photos）を、そのままWebサーバーにアップロードしてください。
index.html がサイトのトップページになります。ビルドや特別な設定は不要です。
※フォルダごとではなく、中身を公開フォルダの直下に置いてください。

【スポットの追加（管理ページ）】
公開したあと、サイトのアドレスの末尾に /admin/ を付けて開きます。
  例）https://（あなたのサイト）/admin/
1. フォームに、地方・スポット名・住所・作品名・ひとこと・写真を入れます。
2. 「住所から位置をさがす」を押します（見つからないときは「地図でえらぶ」）。
3. 「追加する」を押します。登録ずみのスポットは「直す」「削除」でいつでも変えられます。
4. 「更新ファイルを作る」を押して、できたZIPを保存します。
5. Cloudflare Pages の「新しいデプロイを作成」で、そのZIPをアップロードすると公開されます。
ZIPにはサイト全体のファイルが入っているので、手元にフォルダを残しておく必要はありません。
※管理ページのアドレスを知っている人は開けますが、サイトを書き換えることはできません。公開できるのは、Cloudflare にログインできる人だけです。

【構成】
index.html          トップページ（日本地図と地方選択）
regions/*.html      地方ページ（北海道、東北、関東、中部、近畿、中国・四国、九州・沖縄）
admin/              管理ページ（スポットの追加・編集、更新ZIPの作成）
css/style.css       デザイン
js/main.js          タップ時の肉球エフェクト、地図とリストの連動
js/region.js        地方ページの表示（スポット一覧、地図のピン、「行ったにゃ」）
js/spots.js         スポットのデータ（管理ページが書き換えます。手で書き足してもOK）
photos/             スポットの写真

【メモ】
・「行ったにゃ」の記録は、見ている人それぞれのブラウザに保存されます（他の端末や他の人には共有されません）。
・フォントは Google Fonts（Zen Maru Gothic）を読み込みます。読み込めない環境では、標準の丸ゴシック系で表示されます。
・地図は簡略化したイラストです。実際の地形や県境とは違います。
・住所からの位置さがしには、国土地理院の住所検索を使っています。
・サイトにファイルを足したときは、admin/admin.js の先頭にある SITE_FILES にも書き足してください（更新ZIPに入れるファイルの一覧です）。
