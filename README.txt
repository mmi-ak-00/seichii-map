聖ちぃ巡礼マップ - トップページ

【公開のしかた】
このフォルダ（index.html / css / js）を、そのままWebサーバーにアップロードしてください。
ビルドや特別な設定は不要です。index.html を開くと表示されます。

【構成】
index.html      トップページ
css/style.css   デザイン
js/main.js      タップ時の動き（肉球エフェクト、地図とリストの連動）

【地方ページへのリンク】
地図とリストは、次のページへ移動する想定です（まだ作っていません）。
  regions/hokkaido.html
  regions/tohoku.html
  regions/kanto.html
  regions/chubu.html
  regions/kinki.html
  regions/chugoku-shikoku.html
  regions/kyushu-okinawa.html

【メモ】
・フォントは Google Fonts（Zen Maru Gothic）を読み込みます。読み込めない環境では丸ゴシック系の標準フォントで表示されます。
